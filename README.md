# milk_data_find
Finding missing data from missing id tags

My plan for this project is to keep it simple!

1. I will first try to better understand the data
2. I will then look to fix the naming conventions of the data
3. Once the naming conventions are set, I plan on running descriptive statistics to build a range of possible milk yields for each cow.
4. I will then do the same for the other four factors
5. Once that is complete I will use identify which are the most likely fits based on closeness of the other data
6. If that works, I will then shout hooray!
